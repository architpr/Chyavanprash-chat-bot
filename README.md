## 📖 Overview

The **Kerala Ayurveda Wellness Assistant** is an interactive chatbot designed to educate users about **Chyavanprash Lehyam**, a classical Ayurvedic formulation. Built with **Streamlit**, this application provides a premium, brand-aligned experience that mimics the tone of a knowledgeable Ayurvedic expert.

The bot answers questions about:
- 🛡️ **Immunity & Health Benefits**
- 🌿 **Ingredients & Authenticity**
- 👶 **Dosage & Safety for Kids**
- 💰 **Pricing & Purchasing**

---

## ✨ Features

- **Authnetic Persona**: Responses are crafted to be warm, nurturing, and authoritative, using terms like *Ojas* and *Rasayana*.
- **Smart Intent Recognition**: Handles queries about sugar content (diabetic safety), competitors, and seasonal usage specific to Ayurveda.
- **Premium UI**: Custom CSS formulation with a nature-inspired color palette (Deep Greens, Earthy Reds, Soft Creams).
- **Product Showcase**: Sidebar with dynamic product card and direct purchase links.
- **Quick Replies**: One-click buttons for common questions to drive engagement.

## 🚀 Getting Started

### Prerequisites
- Python 3.10+
- pip

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/architpr/Chyavanprash-chat-bot.git
   cd Chyavanprash-chat-bot
   ```

2. **Create a virtual environment**
   ```bash
   python -m venv venv
   # On Windows:
   venv\Scripts\activate
   # On Mac/Linux:
   source venv/bin/activate
   ```

3. **Install dependencies**
   ```bash
   pip install streamlit
   ```

4. **Run the application**
   ```bash
   streamlit run app.py
   ```

## 🧠 Knowledge Base Logic

The bot is programmed with specific logic to handle sensitive topics:

- **Sugar/Diabetes**: Transparently discloses Jaggery & Honey content.
- **Competitors**: Highlights the "Whole Amla" vs. "Pulp/Candy" difference.
- **Seasonality**: Recommends warm milk in winter and cold milk in summer (Pitta season).
